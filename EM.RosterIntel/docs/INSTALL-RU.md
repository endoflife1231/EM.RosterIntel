# Установка EM Roster Intel

## Требования

- Esports Manager 2026 для Windows x64.
- BepInEx 6 для Unity IL2CPP x64.
- После установки BepInEx игру нужно запустить хотя бы один раз, чтобы BepInEx создал папки и IL2CPP-файлы.

## 1. Найдите папку игры

В Steam:

1. Откройте **Библиотеку**.
2. Нажмите правой кнопкой на **Esports Manager 2026**.
3. Выберите **Управление → Просмотреть локальные файлы**.

Открывшаяся папка, в которой находится файл запуска игры, — это корневая папка игры.

## 2. Установите BepInEx

Используйте официальную инструкцию BepInEx для Unity IL2CPP:

https://docs.bepinex.dev/master/articles/user_guide/installation/unity_il2cpp.html

Для обычной Windows-версии игры нужна актуальная сборка `Unity.IL2CPP-win-x64`.

Распакуйте BepInEx непосредственно в корневую папку игры. Запустите игру один раз и затем закройте её. Первый запуск может занять больше времени, поскольку BepInEx создаёт IL2CPP-файлы.

После этого должна существовать папка:

```text
<ПАПКА ИГРЫ>\BepInEx\plugins
```

## 3. Установите мод

1. Полностью закройте игру.
2. Удалите старую версию мода, если она установлена:

   ```text
   <ПАПКА ИГРЫ>\BepInEx\plugins\EM.RosterIntel
   ```

3. Из релизного архива скопируйте папку `EM.RosterIntel` в:

   ```text
   <ПАПКА ИГРЫ>\BepInEx\plugins\
   ```

4. Проверьте конечный путь:

   ```text
   <ПАПКА ИГРЫ>\BepInEx\plugins\EM.RosterIntel\EM.RosterIntel.dll
   ```

Не помещайте ZIP-архив целиком в папку `plugins`: сначала распакуйте его.

## 4. Проверьте установку

1. Запустите игру.
2. Откройте экран состава.
3. Нажмите `F9`.
4. В логе BepInEx должна быть строка:

   ```text
   EM Roster Intel 1.0.0 loading.
   ```

В зависимости от сборки BepInEx лог обычно находится по одному из путей:

```text
<ПАПКА ИГРЫ>\BepInEx\LogOutput.log
<ПАПКА ИГРЫ>\BepInEx\LogOutput.txt
```

## Как получить полный отчёт

1. Откройте состав своей команды.
2. Если статистика неполная, откройте статистику каждого из пяти игроков основы.
3. Для заполнения Transfer Radar откройте составы нескольких других команд.
4. Вернитесь к своему составу и откройте вкладку **Трансферы**.

## Обновление

1. Закройте игру.
2. Удалите старую папку `BepInEx\plugins\EM.RosterIntel`.
3. Распакуйте новую папку `EM.RosterIntel` в `BepInEx\plugins`.
4. Не удаляйте конфигурацию, если в примечаниях к релизу не требуется сброс.

## Сброс настроек

Закройте игру и удалите файл:

```text
<ПАПКА ИГРЫ>\BepInEx\config\com.dignityty.esm26.rosterintel.cfg
```

При следующем запуске файл будет создан заново с настройками по умолчанию.

## Удаление

Закройте игру и удалите папку:

```text
<ПАПКА ИГРЫ>\BepInEx\plugins\EM.RosterIntel
```

При необходимости также удалите файл конфигурации.

## Если окно не появилось

- Нажмите `F9`.
- Откройте экран состава и дождитесь загрузки карточек игроков.
- Проверьте точный путь к DLL.
- Убедитесь, что установлен BepInEx для **Unity IL2CPP x64**, а не Mono-версия.
- Проверьте загрузку BepInEx в его логе.
- Учтите, что обновление игры могло изменить внутренние IL2CPP-типы и нарушить совместимость мода.
