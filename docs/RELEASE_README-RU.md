# EM Roster Intel v1.0.0

Неофициальный мод для анализа состава в **Esports Manager 2026**. Мод работает только на чтение: он не меняет сохранения и состав автоматически.

## Установка

1. Закройте игру.
2. Установите BepInEx 6 `Unity.IL2CPP-win-x64` по [официальной инструкции](https://docs.bepinex.dev/master/articles/user_guide/installation/unity_il2cpp.html).
3. Запустите игру один раз и закройте её.
4. Скопируйте папку `EM.RosterIntel` из этого архива в:

   ```text
   <ПАПКА ИГРЫ>\BepInEx\plugins\
   ```

5. Проверьте, что DLL находится здесь:

   ```text
   <ПАПКА ИГРЫ>\BepInEx\plugins\EM.RosterIntel\EM.RosterIntel.dll
   ```

6. Запустите игру, откройте экран состава и нажмите `F9`.

## Управление

| Действие | Клавиша |
|---|---|
| Показать или скрыть | `F9` |
| Переместить окно | перетащить верхнюю панель |
| Изменить размер | `-` / `+` |
| Сбросить положение и размер | `Backspace` |

Для заполнения Transfer Radar откройте составы нескольких других команд, затем вернитесь к своей команде и откройте вкладку **Трансферы**.

Если мод не загрузился, проверьте путь к DLL, убедитесь, что используется BepInEx для Unity IL2CPP x64, и найдите строку `EM Roster Intel 1.0.0 loading.` в `BepInEx\LogOutput.log` или `LogOutput.txt`.
