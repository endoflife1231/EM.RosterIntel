# Screenshots

Add user-facing screenshots here when available.

Recommended files:

- `roster-overview.png`
- `transfer-radar.png`
- `details-audit.png`

Recommended capture guidelines:

- use the current public release build;
- capture at 1920×1080 or higher;
- crop irrelevant desktop content;
- hide personal paths, save names, account identifiers, notifications, and unrelated overlays;
- use PNG for readable interface text;
- do not include assets you are not permitted to redistribute.

Then add the images to the main README:

```markdown
![Roster overview](docs/screenshots/roster-overview.png)
![Transfer Radar](docs/screenshots/transfer-radar.png)
```
