# Changelog

All notable changes to EM Roster Intel are documented here.

## [1.0.0] - 2026-07-15

### Added

- Read-only roster analysis overlay.
- Team-fit, firepower, IGL, AWP, utility, form, morale, and performance evaluation.
- Starter and bench role analysis.
- Conservative bench-swap recommendations.
- Sport-only Transfer Radar populated from viewed teams.
- Data-source coverage and confidence diagnostics.
- English and Russian user guidance.

### Packaging

- Added MIT license.
- Added universal BepInEx installation instructions.
- Added source project, solution, local-reference build configuration, release scripts, and contribution guidance.
